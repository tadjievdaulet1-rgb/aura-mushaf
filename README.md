# aura-mushaf

Page images of the **Madinah Mushaf** (Hafs 'an 'Asim, 1441 AH print) for the Aura Deen app.
The app downloads them once, when the reader asks for the Madinah mushaf, and then reads them offline.

**Source:** King Fahd Glorious Quran Printing Complex (KFGQPC), Madinah — vector pages
`1441-AI-hafs.zip` from <https://dm.qurancomplex.gov.sa/>.

printing, publishing, websites and computer programs, inside and outside Saudi Arabia
(<https://dm.qurancomplex.gov.sa/rights/>):

**What is here:** the files are in [Releases](../../releases), not in the repository.

| Release | File | Contents |
|---|---|---|
| `hafs-1441-v1` | `hafs1441-1080.zip` | 604 pages, 1080 px wide, cropped to the page frame, 16-colour PNG; `manifest.json` with the verses of each page and the box of every verse-end medallion |

Each page is rendered from the Complex's vector file. The text and its marks are unchanged.
